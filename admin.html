Voting Admin

Election control

Workflow: Association Name Vote → Self-Nomination → Executive Voting → Closed. The same member tokens work through every stage.

Association-name round

If no single name reaches 75%, close the round, review the result, then start a run-off. The same Tokens remain valid. A tie at the second-place cut-off is carried into the run-off rather than being broken arbitrarily.

Nomination controls

Reset removes the old self-nominations only; it does not change member Tokens or association-name votes. The second button is for any position that finishes with no candidate.

Executive election rounds

Only unresolved positions are included in a new round. Once a position has a clear winner it is finalised and will not appear in later rounds. Ties, an Abstain lead, or winner conflicts remain unresolved and can be re-voted.
